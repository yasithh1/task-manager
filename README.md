# Task Manager (MERN)
A full-stack task manager where you can add, edit, complete, and delete tasks.

## Tech stack
React (Vite), Node.js, Express, MongoDB (Mongoose)

## Features
- Create, read, update, and delete tasks
- Mark tasks complete
- Loading and error states

## Run locally
1. Clone the repo
2. Backend:
```bash
   cd server
   npm install
   cp .env.example .env   # then add your MongoDB URI
   npm run dev
```
3. Frontend:
```bash
   cd client
   npm install
   npm run dev
```

## What I learned
- Building REST APIs with Express
- Modelling data with Mongoose
- Using React hooks (useState, useEffect)
- Connecting a frontend to a backend with fetch
- Keeping secrets out of Git with .env
